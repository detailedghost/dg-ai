# DeeGee plugin

The DeeGee plugin publishes the shared browser, demo, prototype, and mailbox
cleanup skills.

Mailbox cleanup is implemented by a frozen provider-neutral extension core.
Its canonical privacy, retention, restart, non-destructive action, debrief,
provider handoff, and conformance-gate documentation is
[Mailbox Cleanup Core](../../docs/mailbox-cleanup/core.md).

Skill-specific instructions live in [`skills/`](./skills/).
