Tab grouping

Tabs group only when opened with a _tab_group marker (the CLI adds it). The name comes from that marker; pick the color here.

Demo narration — video mode

Voice for /dg:demo video recordings, spoken locally by Kokoro TTS. The model downloads once (~86 MB) and is cached.

A recording is captured at whichever is smaller — your window or the preset — so a bigger preset only helps on a bigger display. Higher presets mean much larger files: 2160p can be several times the size of 1080p for the same tour.

Test narration

Loads Kokoro and generates a sample with the selected voice — a quick check that local TTS works here. Preview it, then download the .webm.

Privacy

DeeGee processes prototype, tour, and recording data on your machine. It has no account system, telemetry, or upload service.

  • Prototype sampling is limited. When you start a prototype scrape, DeeGee records the full page URL and inspects a bounded set of rendered page elements, computed CSS, root custom properties, and representative button/input/link styles. The style guide does not include page text or typed form values.
  • Marked URLs are visible to the page. Prototype plans travel in the URL fragment so they are not sent to the website's server, but scripts already running on that page can read the fragment before DeeGee removes it. Do not put secrets in a prototype plan.
  • Site access requires your approval. DeeGee requests the browser's <all_urls> access so marked prototype and tour pages can work on the site you choose. Prototype behavior starts only for a DeeGee-marked URL.
  • Artifacts stay local. Style guides and verdicts go through your Downloads folder. If you approve a prototype and capture is supported, DeeGee also saves a screenshot of the visible tab. The CLI writes the approved answer into your local project. None of these files are uploaded by DeeGee.
  • No telemetry. DeeGee sends no analytics, tracking, page samples, prototype plans, verdicts, recordings, or usage data to us. Settings remain in browser extension storage.
  • Existing network features are separate. Kokoro narration runs locally after downloading its open-source model from Hugging Face. Its ONNX runtime files ship with the extension; the extension also retains jsDelivr access for compatibility with upstream runtime fallbacks. Prototype work does not contact either service. The pages you open may still make their own normal network requests.
